# Tisa Selma — Evidence-based Research Portfolio

This dependency-free website presents verified research, publications, achievements, and attributed professional recognition drawn from supplied primary documents.

## Evidence policy

- Research methods and numerical findings come from the supplied papers.
- All displayed scientific figures are purpose-built reconstructions of the papers' methods and reported results. No journal-page screenshots or page crops are used.
- Peer-reviewed publications are distinguished from the submitted QoE-Foresight manuscript.
- Manuscript results are labeled as not yet peer-reviewed.
- Recommendation excerpts are short, dated, and attributed. The original letters are not included because they contain personal contact details.
- The site contains no synthetic portfolio projects, dummy datasets, simulated results, or claims of KAUST work.

## Figure system

The site uses five coordinated research figures under `assets/figures/`. Each is supplied as an editable SVG and a high-resolution PNG. Cyan marks observed evidence, gold marks human or detection variables, vermilion marks intervention or headline results, and charcoal marks system context.

## Local preview

```bash
python -m http.server 8080
```

Open `http://localhost:8080`.

## GitHub Pages

The included workflow deploys the repository root to GitHub Pages. Create a repository, upload these files, enable GitHub Pages with **GitHub Actions** as the source, and push to `main`.
